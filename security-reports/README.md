# Security Reports Directory

This directory contains security scan reports generated by various security tools.

## Report Types

- `npm-audit.json` / `npm-audit.txt` - NPM dependency vulnerability reports
- `trivy-fs.json` / `trivy-fs.txt` - Trivy filesystem vulnerability scans
- `trivy-secrets.json` / `trivy-secrets.txt` - Trivy secret detection results
- `trivy-docker.json` / `trivy-docker.txt` - Docker image security scans
- `semgrep.json` / `semgrep.txt` - Semgrep SAST analysis results
- `security-summary.md` - Comprehensive security scan summary

## Generating Reports

### Local Scanning
```bash
# Run comprehensive security scan
npm run security:scan

# Individual scans
npm run security:audit
npm run security:trivy
npm run security:secrets
npm run security:docker
```

### CI/CD Scanning
Reports are automatically generated during CI/CD pipeline runs and available as:
- GitHub Security tab findings
- Workflow artifacts
- SARIF uploads

## Report Format

- **JSON files**: Machine-readable format for automation and integration
- **TXT files**: Human-readable format for manual review
- **MD files**: Summary reports with analysis and recommendations

## Security

⚠️ **Important**: These reports may contain sensitive information about vulnerabilities. Do not commit actual report files to version control. Only the directory structure and documentation should be tracked.

## Review Process

1. **Automated**: CI/CD pipeline reviews and blocks on critical findings
2. **Manual**: Security team reviews weekly reports
3. **Response**: Follow incident response procedures for critical findings

For more information, see the main [SECURITY.md](../SECURITY.md) documentation.
